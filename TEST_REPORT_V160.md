## Новый сценарий Web Management

Проверяется полный цикл:

1. Web создание товара.
2. Web редактирование карточки товара.
3. Создание и редактирование поставщика.
4. Создание закупки, изменение позиций и цены, приёмка.
5. Создание заказа клиента, изменение позиций и цены, завершение продажи.
6. Audit событий Web Admin.
7. REST PATCH supplier / purchase / sale.
8. REST cancel для непроведённых purchase / sale.
